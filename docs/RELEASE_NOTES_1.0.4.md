# Folder Size Explorer 1.0.4

## English

Release date: 2026-08-31

Version 1.0.4 adds independent zoom controls for every file view and corrects visual preview orientation in Urdu and other right-to-left interfaces.

### Highlights

- Adjust Details, Columns, Grid, and Dual views independently from 50% to 250% in 5% steps.
- Use the compact status-bar slider, `Ctrl+wheel`, `Ctrl++`, `Ctrl+-`, or `Ctrl+0`; Windows-promoted Precision Touchpad pinch events use the same zoom path.
- Each view remembers its own percentage between sessions. Existing five-level zoom preferences migrate automatically.
- Zoom changes icons, thumbnails, cards, and row spacing while keeping names and metadata readable.
- Enlarged list views load high-resolution Windows Shell icons.
- Image, SVG, PDF, Office, video, icon, and thumbnail content keeps its original orientation in Urdu and other RTL interfaces.
- Grid thumbnails refresh after continuous zoom settles, and keyboard navigation uses the active item width.

## Português (Brasil)

Data da release: 2026-08-31

A versão 1.0.4 adiciona controles de zoom independentes para cada visualização de arquivos e corrige a orientação dos previews em urdu e outras interfaces da direita para a esquerda.

### Destaques

- Ajuste Detalhes, Colunas, Grade e Painel duplo independentemente, de 50% a 250%, em passos de 5%.
- Use o slider compacto na barra de status, `Ctrl+roda`, `Ctrl++`, `Ctrl+-` ou `Ctrl+0`; eventos de pinça do Precision Touchpad promovidos pelo Windows usam o mesmo fluxo.
- Cada visualização mantém seu próprio percentual entre sessões. Preferências antigas de cinco níveis são migradas automaticamente.
- O zoom altera ícones, miniaturas, cards e espaçamento das linhas sem reduzir a legibilidade de nomes e metadados.
- Modos de lista ampliados carregam ícones de alta resolução do Windows.
- Imagens, SVG, PDF, Office, vídeo, ícones e miniaturas mantêm sua orientação original em urdu e outras interfaces RTL.
- Miniaturas da Grade são atualizadas após o ajuste contínuo, e a navegação por teclado usa a largura ativa dos itens.
